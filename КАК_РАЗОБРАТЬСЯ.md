# Как устроен СОБРАНО

Откройте **File → Open Folder → sobrano-clean**, а затем исходные файлы.

| Файл | Что в нём |
| --- | --- |
| `server.py` | Запуск Python-сервера и адреса API |
| `backend/catalog.py` | Чтение товаров, поиск, фильтры и сортировка |
| `backend/compatibility.py` | Правила совместимости и отбор компонентов |
| `backend/pricing.py` | Выбор цены и подсчёт суммы |
| `data/catalog.json` | Модели компонентов и готовые сборки |
| `data/offers.json` | Сохранённые предложения магазинов |
| `js/app.js` | Построение страниц и обработка действий пользователя |
| `js/backend-client.js` | Запросы браузера к Python |
| `css/style.css` | Внешний вид, темы и мобильная версия |
| `index.html`, `catalog.html`, `builder.html` | HTML-страницы |
| `tests/` | Автоматические проверки логики |
| `docs/` | Источники данных, ограничения и объяснение работы |

`backend/__init__.py` обозначает пакет Python. Он может содержать только описание — это нормально.
`__pycache__` и `.pyc` — автоматически создаваемый двоичный кэш Python. Это не фотографии и не исходный код. Открывать их не требуется. В обычном запуске этой копии запись кэша отключена; если другой инструмент всё же создаст его, VS Code скроет его из дерева. Настоящие `.py` остаются видны.

## Запуск

В VS Code: **Terminal → New Terminal**. В нижнем терминале, не в файле, выполните:

```powershell
py server.py
```

Откройте http://127.0.0.1:8080/ . Терминал оставьте открытым. Остановка — Ctrl+C.
Если порт занят: `py server.py --port 8081`, затем http://127.0.0.1:8081/ .

## Как проследить работу

1. В браузере откройте каталог и введите название модели.
2. В терминале появится запрос `/api/products`. Обработчик находится в `server.py`; он обращается к `backend/catalog.py`.
3. В конфигураторе выберите RTX 4090 и откройте блоки питания. Слабые варианты исключаются правилами из `backend/compatibility.py`.
4. Сумма сборки рассчитывается с помощью `backend/pricing.py`.
5. HTML и CSS показывают результат, JavaScript отправляет запросы и обновляет интерфейс. Поэтому весь сайт нельзя называть написанным только на Python.

Разберите хотя бы одно правило и один запрос, затем объясните их своими словами. Подробности и команды тестов — в README.md. Сохранённые магазинные цены имеют даты, остальные оценки подписаны; актуальные цены автоматически не загружаются.
