# СОБРАНО: подготовка к защите

## Что это за проект

СОБРАНО помогает пользователю Казахстана выбрать компьютерные комплектующие, сравнить модели и составить ПК с оценкой бюджета в тенге. Это учебный информационный каталог. Он не принимает заказы и оплату.

Проект решает три задачи: помогает найти подходящую модель, сопоставить характеристики и заметить известные конфликты выбранных деталей. В данных 190 моделей, 22 готовые конфигурации, 8 категорий.

## Технологии простыми словами

- **HTML** задаёт структуру: заголовки, формы, ссылки, основную область страницы.
- **CSS** задаёт внешний вид, размеры, цвета и адаптацию к телефону.
- **JavaScript** реагирует на выбор пользователя, отправляет запрос и выводит результат.
- **JSON** хранит каталог и предложения магазинов, а также служит форматом обмена с сервером.
- **Python** выполняет серверную обработку: читает данные, ищет модели, проверяет совместимость, считает бюджет.
- **HTTP API** — адреса, по которым JavaScript запрашивает данные у Python.
- **localStorage** сохраняет избранное, сравнение и текущую сборку в браузере.

Фронтенд находится в HTML, `css/` и `js/`. Бэкенд находится в `server.py` и `backend/`. Исходники обеих частей доступны отдельно. Внешние платные API и библиотеки не используются.

## Какие функции реализованы

Каталог ищет по словам названия и характеристикам. Фильтры уточняют категорию, бренд, цену и параметры категории; сортировка меняет порядок моделей. Карточка показывает характеристики, цену и источник.

Сравнение выводит до четырёх моделей одной категории в таблице. Избранное хранит выбранные модели. Готовые сборки можно отобрать по задаче и бюджету и загрузить в конфигуратор.

Конфигуратор оценивает сокет, память, форм-фактор, известные размеры и мощность. Выбор работает в разном порядке. Он сохраняет состав, даёт ссылку и TXT. Неизвестная характеристика означает предупреждение, а не доказанную совместимость.

## Запуск перед защитой

1. Откройте в VS Code папку `C:\Users\Студент\sobrano-work\github`.
2. Откройте Terminal → New Terminal.
3. Выполните `python server.py` (или `py server.py`).
4. Откройте http://127.0.0.1:8080/.
5. Заранее откройте вкладки редактора: `catalog.html`, `css/style.css`, `js/backend-client.js`, `server.py`, `backend/compatibility.py`, `data/catalog.json`.
6. В браузере приготовьте F12 → Network → Fetch/XHR. Интернет нужен для внешних фото; без него основные функции продолжают работать.

Если 8080 занят: `python server.py --port 8081`, затем откройте 8081. Терминал должен оставаться запущенным. Остановка — Ctrl+C.

## Два варианта показа

**Опубликованный фронтенд:** https://china1602-glitch.github.io/sobrano/. Здесь Python не запускается: GitHub Pages раздаёт готовые файлы, браузер читает JSON и выполняет клиентские правила.

**Локальный фронтенд и Python:** http://127.0.0.1:8080/ после запуска server.py. Здесь запросы каталога и совместимости обрабатывает настоящий Python-бэкенд.

Быстро открыть исходники и запустить сервер:

```powershell
code "$HOME\sobrano-work\github"
cd "$HOME\sobrano-work\github"
python server.py
```

Хранилища этих адресов раздельные: избранное и текущая сборка не переносятся между Pages и localhost автоматически. Личный состав заранее сохраните ссылкой или TXT. На защите используйте демонстрационный состав.

## Как действительно проходит запрос

Пример для текущего каталога: пользователь выбирает NVIDIA GeForce RTX 4090 с индексом 85.

1. Поле `#slot-gpu` вызывает обработчик `change` в `js/app.js`.
2. `changeComposition` вызывает `Backend.prepare(parts)`.
3. `js/backend-client.js` отправляет **POST /api/configuration** с JSON:
   `{"parts":{"gpu":85}}`.
4. `server.py` читает и проверяет JSON, загружает каталог и цены.
5. `backend/compatibility.py` проверяет состав и каждого кандидата. Для `p40` (DeepCool PK550D) сравнивает 550 Вт с известной рекомендацией GPU и расчётной нижней границей.
6. Python возвращает `parts`, `check`, `budget`, `assessments`. В `assessments.p40.allowed` — `false`.
7. JavaScript получает ответ и обновляет список БП. При ошибке API прежний состав остаётся.

Это реальная обработка Python, проверенная HTTP-запросами и браузером. На GitHub Pages тот же интерфейс использует отдельные клиентские правила, потому что этот хостинг не исполняет Python.

Для независимого показа ответа во втором терминале:

```powershell
$r = Invoke-RestMethod -Uri "http://127.0.0.1:8080/api/configuration" -Method Post -ContentType "application/json" -Body '{"parts":{"gpu":85}}'
$r.assessments.p40 | ConvertTo-Json -Depth 5
```

Не показывайте только `/api/health`: он подтверждает запуск процесса, но правило совместимости видно в `/api/configuration`.

## Вопросы преподавателя

| Вопрос | Краткий ответ |
| --- | --- |
| На каком языке написан сайт? | Интерфейс — HTML/CSS/JavaScript, серверная логика — Python, данные — JSON. |
| Где ваш бэкенд? | server.py принимает HTTP-запросы; backend/catalog.py, compatibility.py и pricing.py выполняют обработку. |
| Почему Python отдельно от JavaScript? | Сервер проверяет запрос и вычисляет результат; браузер отвечает за ввод и показ. |
| Откуда берутся товары? | Из data/catalog.json; предложения магазинов отдельно в data/offers.json. |
| Это база данных? | Это файловое хранилище JSON. SQL и учётные записи для текущей задачи не нужны. |
| Где хранится избранное? | В localStorage браузера, отдельно для каждого адреса/порта. |
| Как работает поиск? | Каждое слово должно находиться в названии, бренде или характеристиках; затем применяются фильтры и сортировка. |
| Как проверяется совместимость? | По известным сокетам, памяти, размерам и питанию. Неизвестные данные показываются предупреждением. |
| Все цены актуальные? | Нет. Есть датированные снимки магазинов и подписанные учебные оценки; автоматического обновления нет. |
| Можно гарантировать совместимость? | Нет. BIOS, QVL, разъёмы и точное исполнение требуют дополнительной проверки. |
| Зачем два режима? | Python нужен для серверной обработки локально; статический режим позволяет бесплатно показывать сайт на GitHub Pages. |
| Почему Pages не запускает Python? | В этой настройке это статический хостинг: он раздаёт готовые файлы, а процесса server.py на нём нет. Для бэкенда запускаю Python локально. |
| Почему на Pages другое избранное? | localStorage разделено по адресу сайта: Pages и localhost имеют разные хранилища. |
| Что при недоступном сервере? | Ошибка показана пользователю. Изменение состава не сохраняется, повтор возможен после восстановления API. |
| Что проверяли? | Автотесты Python и JavaScript, живой API и Chrome в двух режимах, все карточки и сборки, внутренние ссылки и мобильный экран. |
