# СОБРАНО

Учебный информационный сервис по комплектующим и сборкам ПК для Казахстана. Русский интерфейс, цены в тенге. Проект не продаёт товары и не принимает оплату.

При локальном запуске **Python выполняет фильтрацию каталога, подбор совместимых компонентов и расчёт бюджета**. HTML, CSS и JavaScript отвечают за интерфейс и обращения к API. Для публичного просмотра на GitHub Pages предусмотрен отдельный статический режим: Python на GitHub Pages не запускается.

## Запуск в VS Code

Откройте папку, где непосредственно находятся `index.html` и `server.py`. В нижнем терминале Windows выполните:

```powershell
py server.py --port 8080
```

Откройте http://127.0.0.1:8080/ . В терминале отображаются запросы браузера, в том числе обращения к `/api/products` и `/api/configuration`. Сервер работает, пока открыт терминал; остановка — Ctrl+C. Внешние Python-пакеты, Flask, Django и npm для запуска сайта не нужны: используется стандартная библиотека Python 3.

Если команда `py` недоступна, попробуйте `python server.py --port 8080`. Для Linux/macOS — `python3 server.py --port 8080`. Если порт занят, остановите прежний сервер или укажите `--port 8081` и откройте тот же порт в браузере.

Для запуска клавишей **F5** установите бесплатные расширения Microsoft **Python** и **Python Debugger**, выберите интерпретатор через `Python: Select Interpreter`, затем конфигурацию «СОБРАНО: запустить Python-сервер». Настройки — `.vscode/launch.json`. Пошаговая инструкция, отладка правила совместимости и подготовка к защите — [docs/DEFENSE.md](docs/DEFENSE.md).

Для демонстрации Python используйте `server.py`: обычный `py -m http.server` обслуживает только статические файлы и не выполняет бизнес-логику API.

## Как устроен проект

| Файл или папка                                                           | Назначение                                                                               |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| `server.py`                                                              | Запуск HTTP-сервера, маршруты API и выдача страниц                                       |
| `backend/catalog.py`                                                     | Чтение и подготовка каталога, фильтры и сортировка                                       |
| `backend/pricing.py`                                                     | Выбор цены, обработка снимков и расчёт бюджета                                           |
| `backend/compatibility.py`                                               | Проверка состава и отбор кандидатов на Python                                            |
| `data/catalog.json`                                                      | Общий источник: 190 строк моделей, 22 готовые конфигурации и метаданные изображений      |
| `data/offers.json`                                                       | 8 снимков предложений конкретных магазинов с датами и ссылками                           |
| `runtime.json`                                                           | Настройка статического режима; Python-сервер возвращает свой режим по этому же адресу    |
| `js/bootstrap.js`                                                        | Определение режима, загрузка данных и запуск интерфейса                                  |
| `js/backend-client.js`                                                   | Обращения интерфейса к Python API                                                        |
| `js/app.js`                                                              | Отрисовка разделов, события, ссылки, TXT и сохранение в браузере                         |
| `js/core.js`, `js/compatibility.js`, `js/catalog-ui.js`, `js/pricing.js` | Клиентские правила для статического режима GitHub Pages и функции представления          |
| `js/media.js`, `js/product-images.js`                                    | Фото конкретных моделей и линеек, подписи, источники и обработка недоступных изображений |
| `css/style.css`                                                          | Общие стили, адаптация к телефону, светлая и тёмная темы                                 |
| `assets/fonts/`                                                          | Локальный Manrope и его лицензия                                                         |
| `.vscode/launch.json`                                                    | Запуск и отладка Python в VS Code                                                        |
| `tests/`, `docs/`                                                        | Автоматические проверки, ограничения и источники данных                                  |

Девять страниц выполняют разные задачи: главная `index.html`, каталог `catalog.html`, товар `product.html`, готовые сборки `builds.html`, одна сборка `build.html`, конфигуратор `builder.html`, избранное `favorites.html`, сравнение `compare.html`, описание проекта `about.html`. Удалять страницу только из-за похожего имени не следует.

## Локальный API и статический режим

| Запрос                    | Что делает Python                                                                                 |
| ------------------------- | ------------------------------------------------------------------------------------------------- |
| `GET /api/health`         | Возвращает состояние процесса, версию Python и время                                              |
| `GET /api/catalog`        | Передаёт каталог, предложения, подготовленные цены и результаты готовых сборок                    |
| `GET /api/products`       | Возвращает упорядоченные идентификаторы товаров после фильтров, сортировки и отбора совместимости |
| `GET /api/builds`         | Возвращает идентификаторы готовых сборок по задаче и бюджету                                      |
| `POST /api/configuration` | Проверяет выбранные детали, рассчитывает бюджет и доступных кандидатов                            |

При запуске через `server.py` браузер получает режим Python через `runtime.json` и использует API для фильтров и проверки выбранного состава. Ошибка Python API показывается пользователю с возможностью повторить запрос: незаметного перехода на клиентский расчёт в этом режиме нет.

На GitHub Pages используются те же JSON-данные и клиентские правила. Это самостоятельный статический режим, не удалённый Python-сервер. Все внутренние пути относительные, поэтому сайт работает в подпапке `/sobrano/`. Избранное, сравнение и текущая конфигурация сохраняются в `localStorage` браузера с прежним ключом `sobrano:diploma:1`. Серверной SQL-базы, регистрации и синхронизации сохранений между устройствами в этой версии нет.

## Цены, фотографии и совместимость

Сохранены **8 снимков предложений для 7 моделей**. Они помечены как `web-snapshot` и получены из доступного представления страниц магазинов, в том числе поискового кэша. У каждой записи есть магазин, ссылка, дата и условия. Это не поток актуальных цен. Остальные цены — явно обозначенные учебные оценки. Подробнее: [docs/PRICE-SOURCES.md](docs/PRICE-SOURCES.md).

Для расчёта используется минимальный пригодный снимок не старше 30 дней, если товар не помечен отсутствующим; иначе применяется учебная оценка. Доставка, ОС, периферия и работа сборщика в сумму не входят. Автоматического обновления цен нет. Чтобы обновить запись, проверьте страницу магазина и измените `data/offers.json`, сохранив точное соответствие модели, дату и ссылку. Нельзя обновлять одну дату старого снимка.

Изображения сопоставлены с 189 из 190 моделей: 93 точных фотографии и 96 подписанных примеров линейки или исполнения. Для AMD Ryzen 7 5700X3D OEM оставлена заглушка до подтверждения маркировки. Свободные лицензии производителям не приписываются. Источники — [docs/PHOTO-SOURCES.md](docs/PHOTO-SOURCES.md). Внешним фотографиям нужен Интернет; шрифт и интерфейс загружаются локально.

Детали в каталоге принадлежат разным платформам и не совместимы во всех сочетаниях. Конфигуратор проверяет известные сокеты, память, форм-факторы, размеры и ориентир мощности БП. Порядок выбора произвольный, включая GPU → БП. Неизвестные параметры не считаются нулями и перечисляются в результате. Проверка не подтверждает BIOS, QVL, кабели и физические зазоры. Подробнее: [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).

## Обновление готовых файлов

1. Остановите старый сервер через Ctrl+C и сохраните открытые файлы в VS Code.
2. Сохраните прежнюю папку целиком, например как `sobrano-backup-2026-10-20`.
3. Скачайте ZIP текущей версии и распакуйте его в отдельную чистую папку. Откройте папку, где непосредственно лежат `index.html` и `server.py`.
4. Переносите `backend/`, `data/`, `css/`, `js/`, `assets/`, `docs/`, `tests/` и `.vscode/` целиком, сохраняя структуру.
5. Запустите `py server.py --port 8080`, затем обновите браузер через Ctrl+F5.

Копирование всех файлов из подпапок в корень создаёт неиспользуемые дубли. Ранее 22 таких копии удалены после побайтного сравнения с рабочими файлами. Новый ZIP лучше распаковывать в чистую папку, чтобы прежние файлы не оставались вперемешку с новой версией. Пользовательские сохранения браузера для обновления очищать не требуется.

Источник публикации GitHub Pages — ветка с готовыми файлами, папка `/ (root)`. Это публикация статического режима.

## Проверки

Из корня проекта выполните:

```powershell
py -m unittest discover -s tests -p "test_*.py" -v
```

Для JavaScript-тестов статического режима и интерфейсных модулей отдельно нужен Node.js:

```sh
node --test tests/*.test.cjs
```

Условия выполненных проверок и ограничения — [docs/QA.md](docs/QA.md). Список завершённых и оставшихся задач — [docs/TASKS.md](docs/TASKS.md).

Идентификаторы товаров `pN` связаны с положением строки в `data/catalog.json`, составы сборок ссылаются на эти номера. Не переставляйте существующие строки без миграции идентификаторов; новые модели добавляйте в конец.
