# СОБРАНО

«СОБРАНО» — сайт подбора компьютерных комплектующих для Казахстана: **190 моделей, 8 категорий и 22 готовые сборки**. Язык — русский, цены — в тенге. Есть светлая и тёмная темы, поиск, сравнение и конфигуратор.

Основной вариант для защиты — **локальный сайт с сервером Node.js и базой SQLite**. Браузер отправляет запросы серверу, сервер рассчитывает состав и записывает сохранённые сборки в базу. Регистрация и вход работают на сервере; пароль не хранится в localStorage. Отдельная программа на Python/Tkinter включена для требований ПМ 6.

## Запустить сайт в VS Code

1. Установите бесплатный **Node.js 24 LTS или новее** с https://nodejs.org/. После установки перезапустите VS Code.
2. Распакуйте архив в отдельную папку. В VS Code выберите **File → Open Folder** и откройте папку, где находятся `package.json`, `index.html` и `online/`. Можно открыть `sobrano.code-workspace`.
3. Выберите **Terminal → New Terminal**. Введите **в терминале**, а не в файле кода:

```powershell
node --version
node online/server.mjs
```

4. Откройте **http://localhost:8080/**. Это локальный адрес без имени и почты. Терминал оставьте работающим; остановка — **Ctrl+C**.

Можно использовать **START.bat**, **START-ONLINE.bat** или F5 → **«СОБРАНО: онлайн-бэкенд Node.js + SQLite»**. Для этого запуска не нужны npm-пакеты и отдельная установка SQLite: HTTP и SQLite входят в Node.js.

Если порт занят, сначала остановите прежний сервер или запустите:

```powershell
node online/server.mjs --port 8081
```

Тогда адрес — http://localhost:8081/. Не открывайте HTML двойным щелчком: это обходит сервер. Во время демонстрации используйте один адрес (`localhost`), поскольку `localhost` и `127.0.0.1` имеют разные cookie браузера.

## Проверить основной сценарий

1. Откройте **«Аккаунт»**, зарегистрируйте свой учебный логин и пароль. Готовых общих паролей в исходниках нет.
2. В каталоге найдите компонент и откройте его характеристики. Проверьте фильтр, сортировку и сравнение двух моделей.
3. В конфигураторе выберите RTX 4090: заведомо недостаточно мощные блоки питания исчезнут из списка.
4. Нажмите **«Сохранить на сервере»**, введите название и сохраните. Появится ссылка на состав из базы.
5. Выйдите из аккаунта. В другом браузере на **том же адресе** войдите под тем же логином: ваши сохранённые сборки будут доступны.
6. Общую ссылку можно открыть без входа для просмотра. Чужому посетителю недоступно изменение оригинала; он может сделать свою копию.
7. Проверьте неверный пароль и пустое/неверное поле. Интерфейс должен показать понятную ошибку, а сервер — отклонить запрос.

Сохранение в базу выполняется по команде пользователя. Избранное, сравнение и текущий несохранённый выбор остаются в localStorage конкретного браузера — они не синхронизируются через аккаунт.

## Где данные и что сохранить перед переносом

Локальная база — **`instance/sobrano.sqlite`**. Она появляется при первом запуске и содержит серверные данные, аккаунты и сохранённые составы. Обычный перезапуск не очищает базу. Для резервной копии остановите сервер и скопируйте весь каталог `instance/` в безопасное место. Не загружайте его в публичный GitHub.

Исходные модели находятся в `data/catalog.json`, датированные предложения магазинов — в `data/offers.json`. При запуске сервер загружает исходный каталог в SQL, сохраняя порядок идентификаторов. Ручное изменение индексов моделей может испортить связь с прежними составами.

Пароли хешируются с отдельной солью; открытые пароли не записываются в базу или Git. Запросы записи требуют сессию и CSRF. Это учебный сервис без восстановления пароля по почте, платежей и админки магазина. Названия и составы по общей ссылке доступны её получателю — не вводите личные данные в название сборки.

## Отдельное приложение на Python

В другом терминале той же папки:

```powershell
py desktop_app.py
```

Либо **START-DESKTOP.bat**. Нужен Python 3.10+ с Tkinter. Проверка компонента: `py -m tkinter`. Если `py` отсутствует, используйте `python`. Внешние pip-пакеты не требуются.

Программа **«СОБРАНО — расчёт сборки»** открывает окно с каталогом, загружает готовый состав, позволяет менять детали, считает бюджет, сохраняет JSON и экспортирует TXT. Она использует модули `backend/`, но не требует запущенного веб-сервера. Её JSON — отдельный файл, а не запись веб-аккаунта.

## Локальная и опубликованная версии

`localhost` доступен на вашем компьютере, пока работает сервер. По общей локальной ссылке другие люди из интернета не подключатся. Для демонстрации на телефоне в одной доверенной Wi-Fi-сети:

```powershell
node online/server.mjs --host 0.0.0.0
```

Во втором терминале выполните `ipconfig`, найдите IPv4 компьютера и на телефоне откройте `http://ВАШ-IPv4:8080/`. Не вводите `0.0.0.0` в браузер. Брандмауэр и изоляция устройств в сети могут препятствовать соединению. Для обычной защиты на одном компьютере этот режим не нужен.

Ранее опубликованная облачная версия использует Cloudflare Workers и D1; пользователь подтвердил в ней сохранение и открытие ссылки. Новая локальная версия с аккаунтами — отдельное обновление: не следует утверждать, что оно уже размещено по старому интернет-адресу, без отдельной публикации. Локальная SQLite и облачная D1 — разные базы.

GitHub хранит код. GitHub Pages показывает статические файлы и не запускает Node.js, Python или SQL API. Старый `py server.py`/START-PYTHON.bat сохранён как прежний Python API; он не реализует новую авторизацию. Статический просмотр через `py -B -m http.server 8000` также не заменяет основной сервер.

## Проверки и сборка

Для обычного локального запуска предыдущих команд достаточно. Для разработки и полного JS-набора установите dev-зависимости из lockfile, затем выполните:

```powershell
npm ci
npm run build
node tools/test-javascript.cjs
node tests/browser-smoke.cjs
py -B -m unittest discover -s tests
```

Worker-тесты используют результат сборки, поэтому `build` идёт первым. Браузерным проверкам нужен Chrome/Chromium. Python GUI-тесты без графического экрана пропускаются; такой пропуск не доказывает работу окна. В отчёте проверок указаны выполненные команды и ограничения, а не обещание отсутствия любых ошибок.

## Границы данных

Это независимый информационный проект, а не магазин. Есть **8 датированных предложений для 7 моделей**; остальные цены отдельно отмечены как расчётные. Автоматического обновления цен и наличия нет. Снимки старше 30 дней исключаются из расчёта как магазинные цены.

Фотографии привязаны к источникам; для части моделей используется подписанное изображение линейки. Внешним фото нужен Интернет; без него может появиться состояние «Фото недоступно». Не выдавайте пустой кеш за готовый локальный набор фото. Необязательные команды: `py tools/cache_images.py`, затем `py tools/cache_images.py --check`.

Совместимость учитывает известные сокеты, тип памяти, форм-фактор, размеры и оценку мощности. Отсутствующая характеристика не является гарантией совместимости. BIOS, QVL, разъёмы, крепления и охлаждение проверяются не полностью. Подробнее: [совместимость](docs/COMPATIBILITY.md), [фото](docs/PHOTO-SOURCES.md), [цены](docs/PRICE-SOURCES.md).
