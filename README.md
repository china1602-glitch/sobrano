# Практикум · версия 1.1

Локальное приложение для студенческой IT-практики: задачи, дневник по дням, календарь, учёт часов, практические памятки и печатный отчёт. Python выполняет проверки, расчёты и сохранение в SQLite. HTML, CSS и JavaScript показывают интерфейс и отправляют HTTP-запросы.

## Запуск на Windows в VS Code

1. Распакуйте архив в отдельную папку. Папку из GitHub с длинным именем можно переименовать в `praktikum`. Не переносите файлы в СОБРАНО.
2. В VS Code выберите **File → Open Folder**, затем папку `praktikum`, в которой непосредственно лежит `server.py`. Кнопка Open File открывает один файл и здесь не подходит.
3. Откройте **Terminal → New Terminal**. В нижнем терминале выполните:

```powershell
py server.py
```

4. Откройте **http://127.0.0.1:8090/** в браузере. Терминал оставьте открытым.
5. В настройках заполните данные практики, план часов и длительность одного часа: 60 или 45 минут. План 144 часа и выбор 60 минут — начальные значения, а не требования колледжа; укажите согласованные с руководителем параметры.
6. Создайте задачу, добавьте день в дневник или через календарь и откройте отчёт. Для знакомства с заполненным интерфейсом нажмите «Открыть пример».

Команду `py server.py` вводят в терминале, не в файле Python. Никакого установщика и копирования длинного кода не требуется. Для следующих запусков можно открыть `start.bat` двойным щелчком. Сервер сам не открывает браузер.

Нужен установленный **Python 3.10 или новее**. Внешние Python-пакеты, npm, платные сервисы и Интернет для работы приложения не нужны. Если команда `py` не найдена, попробуйте `python server.py` или установите Python с python.org. Остановка сервера — **Ctrl+C** в терминале.

Если порт занят: остановите старый процесс или запустите `py server.py --port 8091`, затем откройте http://127.0.0.1:8091/. Для Linux/macOS используйте `python3 server.py`.

## Запуск и отладка клавишей F5

Установите бесплатные расширения Microsoft **Python** и **Python Debugger** в VS Code. Выберите интерпретатор через `Ctrl+Shift+P → Python: Select Interpreter`. Нажмите F5 и выберите «Практикум: Python-сервер». Перед F5 остановите уже работающий сервер на том же порту.

В `.vscode/launch.json` указаны настоящий `server.py`, рабочая папка и порт. Отладчик останавливается в обычных `.py`-файлах. Разбор программы: [docs/КАК_УСТРОЕНО.md](docs/КАК_УСТРОЕНО.md).

## Что работает

- Создание, изменение и удаление задач, статусы, приоритеты, сроки и поиск на сервере.
- Одна редактируемая запись дневника на день, связь с задачей и направлением. Кнопка записи сегодняшнего дня открывает уже существующую запись, если она есть.
- Календарь по месяцам: сохранённые дни, фактическое время и переход к редактированию или добавлению дня.
- Расчёт минут на Python: окончание минус начало минус перерыв.
- План в часах по 60 или 45 минут; пересчёт зачтённых часов без изменения исходных записей времени.
- Проверки обязательных полей, будущих дат, периода практики и ошибочного времени.
- Статистика и недельная диаграмма из сохранённых записей.
- Шесть разных локальных иллюстраций и памятки с практическими заданиями и официальными источниками.
- Печатный отчёт за выбранный период; PDF через диалог печати браузера, CSV для табличного редактора.
- Резервная JSON-копия и восстановление после подтверждения. Перед заменой сохраняется предыдущая версия.
- Светлая и тёмная темы, мобильная вёрстка, формы с подписями и клавиатурная навигация.
- Отдельные личная база и учебный пример. Ошибки сохранения не стирают введённый текст.
- Предупреждение перед уходом с изменённой формы и локальные черновики новой задачи или записи дневника.
- Явное сообщение об ошибке поиска или фильтрации: старый результат не выдаётся за ответ на новый запрос.
- Защита от перезаписи устаревшей вкладкой: версия данных проверяется перед изменением.

После первого запуска рядом появится `storage/`: `personal.sqlite3`, `demo.sqlite3` и при восстановлении `backups/`. В архиве нет чужих личных записей, кэша Python и снимков интерфейса. `.pyc` — двоичный кэш Python, его не нужно открывать; это не исходник. В обычном запуске создание кэша модулей проекта отключено. При запуске тестов сторонний инструмент может создать его; VS Code скрывает только эти служебные файлы.

## Данные и перенос

**«Открыть пример»** переключает на отдельную демонстрационную базу с явно обозначенными вымышленными записями. Переключение не заполняет и не очищает личную базу. Первая дата примера определяется при его первом создании; записи остаются сохранёнными между перезапусками.

Для переноса: в настройках скачайте JSON-копию; на другом компьютере запустите проект, выберите тот же режим и восстановите файл. Операция заменяет данные выбранного режима только после проверки и подтверждения. Предыдущее состояние сохраняется в `storage/backups/`. Не отправляйте личные копии и `storage/` в публичный репозиторий.

Можно скопировать всю папку `storage/`, **остановив сервер на обоих компьютерах**. Сохранённые записи находятся на сервере в SQLite; тема и выбор режима — в localStorage браузера, черновики новых форм — в sessionStorage текущей вкладки до её закрытия. Черновик сохраняется при обновлении страницы, но не заменяет запись в SQLite. Другой браузер на том же сервере увидит ту же базу, но не получит локальные черновики первого браузера.

Черновик помогает вернуть текст незавершённой новой записи; он не добавляет часы в статистику и не заменяет сохранение на сервере. При работе на общем компьютере учитывайте, что данные браузера доступны пользователям этого профиля.

## Как считаются часы

Время начала и окончания всегда задаётся по обычным часам. Python вычитает перерыв и сохраняет фактические минуты. Настройка «Длительность часа» определяет только пересчёт для плана и отчёта:

- 09:00–17:30 с перерывом 60 минут — **450 фактических минут**, то есть 7 ч 30 мин.
- При часе по 60 минут это **7,5 часа** в зачёт плана.
- При академическом часе по 45 минут это **10 академических часов** в зачёт плана.

План 144 часа при длительности 60 минут соответствует 8 640 минутам, а при 45 минутах — 6 480 минутам. Выбирайте значение по требованиям своей практики. Изменение этой настройки не меняет сохранённые минуты и описания работ; меняются зачтённые часы, объём плана в минутах и процент выполнения.

Старые профили и JSON-копии версии 1 без `hour_minutes` читаются с длительностью часа **60 минут**. Формат резервной копии остаётся совместимым с прежней версией.

## Обновление с сохранением записей

1. В работающем приложении скачайте JSON-копию своих данных через настройки.
2. Остановите сервер клавишами **Ctrl+C**. Сохраните прежнюю папку проекта целиком как резервную копию.
3. Распакуйте новую версию в отдельную папку и проверьте, что в ней есть `server.py`, `app/` и `web/`.
4. Перенесите свою прежнюю папку **`storage/` целиком** в новую папку рядом с `server.py`. Сохраните также прежнюю копию `storage/`; не удаляйте и не заменяйте её пустой папкой из другого проекта.
5. Запустите новую версию командой `py server.py`, откройте тот же адрес и обновите страницу через **Ctrl+F5**. Проверьте настройки, записи дневника и итог часов.

Если обновляете файлы непосредственно в прежней папке, заменяйте исходный код, но сохраняйте существующую **`storage/`**. Удаление папки `storage/` удалит серверные записи. Для переноса через JSON восстановите скачанную копию в том же режиме после запуска новой версии.

## Границы версии

Приложение предназначено для одного пользователя на локальном компьютере. Нет регистрации, облачной синхронизации и проверки подписей руководителя. HTTP-сервер слушает только 127.0.0.1; посторонние устройства к нему не подключаются. Публикация HTML на GitHub Pages не запускает этот Python backend.

Отчёт является личным дневником; соответствие официальной форме колледжа проверяют отдельно. Приложение сохраняет фактическое время и пересчитывает его в выбранные часы по 60 или 45 минут. Одна запись содержит не более 12 фактических часов и не пересекает полночь. План, единицу его учёта и сроки задаёт пользователь.

Приложение не подтверждает уровень навыков и не создаёт фиктивные подписи или факты прохождения практики. В рабочей базе записи изначально пустые.
