# Источники фотографий

Фотографии сопоставляются по точному названию модели. Суффиксы OEM/BOX у CPU не меняют сам процессор. Общие снимки категорий не используются вместо отсутствующего фото товара. Для единственной фотографии NVIDIA RTX 3090 явно указана референсная версия Founders Edition; на конкретные MSI/Sapphire эта запись не распространяется.

Внешние JPEG/PNG-превью загружаются из Wikimedia Commons. Внешний доступ нужен только для фотографий. При отказе сети интерфейс показывает нейтральный значок и подпись. Показ в рамке без изменения содержания; уменьшение выполняет браузер/сервер Commons. Автор, ссылка на исходник и лицензия доступны рядом с каждым фото и на странице данных.
