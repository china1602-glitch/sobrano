## Что означают эти записи

В `js/offers.js` находятся восемь ценовых снимков для семи моделей из `js/data.js`. Названия, ёмкости, комплектация и обычная онлайн-цена сверены по первичным страницам магазинов. Идентификатор `pN` обозначает исходный номер товара, начиная с нуля; строки набора товаров нельзя переставлять без миграции идентификаторов.

Источники прочитаны через инструмент просмотра веб-страниц. Этот инструмент может возвращать индексированный или кэшированный снимок. Поэтому `checkedAt` означает время получения и проверки доступного снимка, **а не время подтверждённого прямого запроса к серверу магазина**. Каждая запись имеет `sourceMethod: "web-snapshot"`, `snapshotOnly: true` и `captured: true`.

В интерфейсе следует писать «Зафиксированная цена» и показывать дату. Нельзя называть эти записи «актуальными», обещать наличие, доставку или сохранение цены. Автоматического обновления в статической версии нет. Цены не включают доставку и работу сборщика.

## Достоверность сравнения

Для Kingston NV3 1000 ГБ есть две записи разных магазинов с одним UID `SNV3S/1000G`, поэтому их можно показывать рядом. Разница между указанными снимками — 1 000 ₸. Это не утверждение о минимальной цене на всём рынке.

Цены в `js/data.js` остаются отдельными учебными оценками для расчёта сборок. Их нельзя автоматически выдавать за суммы покупки в магазинах: для большинства деталей нет проверенной магазинной цены, а часть снимков привязана к региону. При смешанном расчёте интерфейс должен явно объяснять используемую основу.

## Как обновить

1. Открыть первичную страницу магазина и убедиться, что совпадают модель, UID, ёмкость и комплектация.
2. Записать полную онлайн-цену в KZT. Исключить рассрочку, размер скидки и бонусы.
3. Обновить `checkedAt`, способ получения и примечание. Наличие менять только при явном подтверждении на странице.
4. Если цену подтвердить нельзя, удалить запись из массива либо оставить её только в отдельно обозначенной истории. Не подставлять придуманное значение.
