# Проверка версии от 20 октября 2026

Проверены файлы этой версии в Chromium. Прямой адрес GitHub Pages и внешние бинарные фотографии недоступны из сети среды проверки; интерфейс проверялся на локальном сервере, включая размещение в подпапке `/sobrano/`.

## Обновление: отбор компонентов и фотографии

- 47 модульных проверок проходят. Добавлены 15 проверок подбора кандидатов и 8 проверок изображений: приоритет точной модели, OEM/BOX, явные подписи линейки, безопасные ссылки, отсутствие вымышленных лицензий и фактическое покрытие 189 из 190 товаров.
- 11 групп новых браузерных сценариев: GPU → БП без CPU, обратный порядок, память до CPU/платы, корпус до платы/GPU, старые конфликтные составы, очистка, сохранение фокуса, переключатель каталога, общие ссылки и синхронизация вкладок.
- Повторно проверены удаление и замена старой конфликтной видеокарты: после изменения лишняя опция исчезает, поле остаётся в фокусе.
- Повторно проверены все 22 состава: суммы компонентов совпадают с итогом, известных конфликтов нет; 12 составов проходят заполненные базовые проверки, 10 требуют уточнения данных. Это не подтверждение полной аппаратной совместимости.
- Повторены 90 состояний адаптивности и 37 состояний Axe WCAG для девяти страниц. В новых сценариях отбора дополнительно проверены 12 состояний Axe. Нарушений в выполненных проверках нет.
- Избранное, сравнение, снимки цен, передача состава, копирование ссылки, TXT, повреждённые URL и работа при запрете хранилища проверены повторно.
- 22 удалённых корневых дубля побайтно совпадали с файлами внутри рабочих папок. Все девять HTML-страниц и их локальные ресурсы сохранены. Исходные 190 строк товаров, цены и индексы 22 сборок не изменены.

Новые ссылки на изображения получены из карточек производителей, розничного каталога Newegg и ранее проверенных страниц Commons. Источник и характер изображения сохранены в `js/product-images.js` и [PHOTO-SOURCES.md](PHOTO-SOURCES.md). Браузерные тесты в этой среде не подтверждают загрузку внешних фотографий у посетителя: такие запросы ограничены сетью среды. Проверены сопоставление, подписи, атрибуция и обработка отказа загрузки без циклов. Для Ryzen 7 5700X3D оставлена заглушка до визуального подтверждения маркировки.

## Локальный Python-сервер

Добавлен `server.py` на стандартной библиотеке Python. Выполнены четыре интеграционных теста: живой JSON `/api/health`, HEAD без тела, загрузка страницы и скрипта, HTTP 404 для отсутствующего файла. Проверены занятый порт, некорректный номер порта и запуск абсолютного пути к серверу из другой рабочей папки.

Все девять страниц загружены в Chromium через новый сервер; выбор RTX 4090 исключает БП 550 Вт. Ошибок JavaScript и отсутствующих локальных ресурсов не было. Проверка выполнена в Linux с Python 3.12.14; она не выдаётся за запуск на компьютере пользователя. JSON-файлы настроек VS Code корректны. Интерактивный запуск F5 и собственные скриншоты пользователь делает в своём VS Code по [DEFENSE.md](DEFENSE.md).

Команда: `py -m unittest discover -s tests -p "test_*.py" -v`. На Linux вместо `py` используется `python3`.

## Предыдущая проверка интерфейса

- 24 исходных модульных проверки: составы, конфликты, неполные данные, передача индексов, категории, фильтры, отображаемые цены, истечение срока снимков и смешанный бюджет.
- 15 групп браузерных сценариев: поиск, сортировка, фильтры, избранное, сравнение, составы, ссылки, фокус, TXT, копирование ссылки, ограничения хранилища и относительные пути.
- 90 состояний адаптивности: 9 страниц, 5 ширин от 320 до 1440 px, 2 темы. Горизонтального переполнения страницы не обнаружено; широкие таблицы прокручиваются внутри своего блока.
- 37 состояний проверки Axe WCAG без найденных нарушений. После увеличения мобильного текста отдельно перепроверен каталог в обеих темах.
- Проверены повреждённая ссылка, сохранение чужой сборки при переходах и синхронизация состояния/адреса между вкладками.
- Необработанных JavaScript-ошибок и отсутствующих локальных ресурсов в выполненных сценариях не было.

На экране шириной 390 px: основной текст 18 px, характеристики 13 px, название товара 16 px. Первый товар находится примерно на 487 px от начала страницы (в прежней версии — примерно 1337 px).

Снимки интерфейса находятся в [screenshots/](screenshots/). Внешние фотографии при проверке не загружались: на снимках может быть сообщение о недоступном фото. Сопоставление моделей и безопасная обработка отказа изображения проверены; доступность Wikimedia для реального посетителя этими тестами не подтверждена.

Проверка доступности автоматическим инструментом не заменяет ручную проверку скринридером. Подлинность каждой из 190 спецификаций и текущее наличие товаров в магазинах не утверждаются.
