# СОБРАНО: доработка и проверка для ПМ 6

Дата: **22 октября 2026 года**. Исходная версия: `main`, commit `0b9be3eb6a69dac60fe675b30f1d99f20dda1849`. Доработки выполнены в отдельной рабочей копии и ветке `finish/pm6-2026-10-22`. Прежние локальные папки не изменялись; исходная версия сохранена в резервном ZIP и истории Git.

## Что было обнаружено

В исходной версии уже были девять страниц, поиск и фильтры, сравнение, избранное, 22 сборки и настоящий Python HTTP API. Данные — 190 моделей и восемь сохранённых предложений магазинов для семи моделей. SQL, аккаунтов, заказов, админки и отдельного оконного приложения не было.

Подтверждены ошибки: бюджет 0 отключал фильтр готовых сборок; инструкция запуска требовала папку с другого компьютера; локальная ссылка ошибочно обещала доступ с другого устройства. Все фотографии зависели от внешних сайтов.

Документ «Основные вопросы для защиты по ПМ 6» требует выступление 5–6 минут, Python-приложение, объяснение frontend/backend, реальный запрос и результат, успешную операцию и обработку неверных данных. Обязательного требования SQL или админки в документе нет. Для информационного каталога они не добавлялись: продажи и личные кабинеты не имитируются.

## Что исправлено и добавлено

- Пустой бюджет означает отсутствие ограничения, 0 ₸ — нулевой бюджет. Отрицательные, дробные и некорректные значения отклоняются интерфейсом и API.
- Локальная ссылка сопровождается точным пояснением. Отдельная ссылка переносит тот же состав на существующий статический сайт Pages.
- `server.py --host 0.0.0.0` включает доступ из общей локальной сети. Обычный запуск сохраняет адрес 127.0.0.1.
- Добавлено отдельное приложение `desktop_app.py`: готовые составы, выбор деталей в любом порядке, фильтрация известных конфликтов, бюджет, JSON-сохранение/открытие и TXT-экспорт. Оно использует общие Python-модули сайта.
- Файлы состава проверяются до замены текущего выбора: формат, версия, категории, модели и известные конфликты. Неправильный файл не стирает выбор. Существующий файл не перезаписывается без подтверждения.
- Добавлены START.bat, START-DESKTOP.bat, `sobrano.code-workspace`, отдельная конфигурация F5 и переносимая команда JS-тестов. Установщик с кодом сайта не используется.
- Подготовлены единая инструкция запуска, карта исходников, разбор frontend/backend и выступление на 5:45. Второй конкурирующий документ защиты заменён ссылкой на основной.
- Добавлен необязательный загрузчик `tools/cache_images.py`: сохраняет уже сопоставленные фотографии и их источники для работы без Интернета. Повреждённый кеш восстанавливается с резервной копией; HTML-ошибка не сохраняется как изображение.

Каталог, цены, номера моделей, составы сборок и существующие функции сохранены. Не создавались фиктивные магазинные предложения, отзывы, партнёрства или гарантии совместимости.

## Фактические проверки

Среда: Linux; HTTP-сценарии — Python 3.12.14, полный Python/GUI-прогон — Python 3.13.5 и Tk 8.6 на виртуальном экране Xorg; Node.js 24.19.0; Chromium 151.0.7922.173.

| Проверка | Результат |
| --- | --- |
| Все Python-тесты, включая HTTP и настоящее Tk-окно | 86 успешно, ошибок и пропусков нет |
| JavaScript-тесты | 63 успешно, ошибок и пропусков нет |
| Chromium: статический и Python-режим | 40 групп успешно |
| Синтаксис всех Python и JavaScript исходников | Успешно |
| Структура JSON, ссылки и целостность каталога | Успешно: Python-набор и браузерные проверки |
| Реальный запуск CLI с `--host 0.0.0.0` | Успешно: HTTP-запросы и остановка своего процесса |

В браузере проверены девять разделов, страницы всех 190 моделей и 22 сборок в обоих режимах, поиск, сортировка, пагинация, отсутствие результатов, избранное, сравнение, TXT, ссылки и перенос состава. Проверены нулевой/пустой/неверный бюджет, исключение слабого БП после RTX 4090, сохранность состава при отказе API и очистка localStorage в другой вкладке. На ширине 390 px проверены все страницы, обе темы, меню и отсутствие горизонтальной прокрутки.

Отдельная проверка Python-окна: загрузка готовой сборки → сохранение JSON → экспорт TXT → очистка → повторное открытие. Неверный JSON сохраняет предыдущий состав; отказ от перезаписи оставляет файл нетронутым. Окно фактически создано в графической среде и просмотрено. В автоматической проверке выбора файлов диалоги подменяются заранее заданными временными путями; Windows-диалоги вручную здесь не проверялись.

Реальный HTTP-пример: POST `/api/configuration` с `{"parts":{"gpu":85}}` возвращает для p40 `allowed: false` (RTX 4090 и DeepCool PK550D 550 Вт). Несуществующий индекс 9999 возвращает HTTP 400 с сообщением «Неверный номер компонента в категории gpu». GET `/api/builds?budget=0` возвращает пустой список. Это расчёт на сервере, а не запись в базу.

Команды повторной проверки из папки проекта:

```powershell
py -B -m unittest discover -s tests
node tools/test-javascript.cjs
node tests/browser-smoke.cjs
```

GUI-тесты требуют доступного графического экрана; без него они явно пропускаются. Браузерным тестам нужны Chrome/Chromium и Node.js 22+. В Linux CI без поддержки Chromium sandbox использован отдельный параметр окружения `SOBRANO_CHROME_NO_SANDBOX=1`; для обычного запуска он не нужен.

## Что остаётся и что не проверено

1. **Фотографии.** Из этой среды внешние источники возвращают блокировку прокси. Локальных фото фактически **0 из 149 уникальных изображений**, сопоставленных с 189 товарами. Это ограничение не устранено обещанием кеша. На компьютере с доступом к источникам выполните `py tools/cache_images.py`, затем `py tools/cache_images.py --check`. Полный кеш не гарантируется при отказе источника. У Ryzen 7 5700X3D подтверждённая фотография отсутствует. Некоторые изображения представляют линейку, что подписано; одинаковые фото линейки не выдаются за разные точные модели.
2. **Достоверность данных.** Магазины не опрашиваются автоматически. Есть датированные снимки и отдельно отмеченные расчётные цены. Из 47 видеокарт у 42 не указана длина; универсальная модель GPU не определяет размеры всех её исполнений. Неизвестные данные не подменены вымышленными.
3. **Совместимость.** Известные конфликты скрываются. BIOS, QVL, кабели, крепления, охлаждение, точная геометрия и отсутствующие характеристики полностью не проверяются. Нельзя обещать совместимость любого доступного варианта.
4. **Размещение.** Изменения проверены локально. Само наличие старого адреса https://china1602-glitch.github.io/sobrano/ не означает публикацию этой версии. Прямую проверку публичного сайта блокирует политика сети среды (HTTP CONNECT 403); это не доказательство неисправности сайта. До отправки и отдельной проверки актуального URL публикация не считается завершённой.
5. **Устройства.** Настройки F5 и .bat подготовлены для Windows, но интерфейс VS Code и брандмауэр на компьютере пользователя здесь не запускались. Открытие на физическом телефоне требует проверки в его Wi-Fi-сети.
