# Проверка СОБРАНО: локальный сайт с аккаунтами

Дата: **28 октября 2026 года**. Основной комплект для защиты — Node.js 24 + SQLite, frontend HTML/CSS/JavaScript и отдельное приложение Python/Tkinter. [Запуск](../README.md), [соответствие ПМ 6](PM6_REQUIREMENTS.md), [задачи и ограничения](TASKS.md).

## Что реализовано

- Десять HTML-страниц, 190 моделей в восьми категориях, 22 готовые сборки; исходные идентификаторы и данные сохранены.
- Серверные поиск, фильтры, сортировка, совместимость и расчёт стоимости. Индекс 0 допустим; пустой бюджет отличается от нулевого, неверные значения отклоняются.
- SQLite хранит каталог, гостевые сессии, аккаунты, сессии аккаунтов, ограничения попыток и сохранённые сборки — семь таблиц.
- Регистрация по логину без почты, вход, выход, личный кабинет. Сборки одного аккаунта доступны из независимых браузерных сессий, подключённых к тому же серверу.
- Сохранение, общая ссылка, обновление с проверкой версии и удаление своей записи. Повтор того же запроса не создаёт дубль. Чтение общей ссылки доступно получателю; редактирование и удаление проверяются по владельцу на сервере.
- Гостевые сборки текущей сессии переходят в аккаунт при входе. Записи другого аккаунта не переносятся. Лимит 50 проверяется атомарно, в том числе при одновременном импорте.
- Пароли: PBKDF2-SHA256, отдельная случайная соль; токены сессий в базе хешируются. HttpOnly/SameSite cookie, Secure на HTTPS, CSRF и Origin, ограничение попыток по логину и адресу клиента. Пароли/токены не сохраняются в localStorage.
- Старый Python API сохранён, но не выдаётся за сервер новой авторизации. Его HTTP-выдача ограничена ресурсами интерфейса: база и исходники не отдаются даже при случайном запуске старого сервера.
- Избранное, сравнение и несохранённый состав остаются локальным состоянием браузера. Отдельная Python-программа сохраняет собственные JSON/TXT-файлы.

### Что проверяют тесты сервера и SQL

Реальные HTTP-запросы к Node.js с временным SQLite-файлом: каталог и расчёт, неверные индексы и категории, JSON/Content-Type/размер тела, нулевой бюджет, совместимость, ошибки методов и закрытые файлы. Данные перечитываются после закрытия и повторного открытия базы.

Проверены регистрация, занятый нормализованный логин, неверные поля/пароль, индивидуальные соли, истечение и отзыв сессии, ротация cookie/CSRF, независимый вход из двух браузеров, сохранность после перезапуска, чужое изменение/удаление, импорт гостя, отсутствие переноса чужого аккаунта, ограничения попыток. Проверены повторное сохранение, конфликт версии, квота и одновременный импорт без потери отклонённого черновика.

Собранный Worker импортируется локально и получает реальный SQLite-адаптер. Перед запросами исполняются обе сгенерированные миграции. Проверяются ресурсы и бинарные шрифты, инициализация каталога, Secure-cookie, регистрация и второй вход с теми же сборками. **Это не проверка новой авторизации на облачном D1.**

### Что проверено в браузере

Три режима: статический, прежний Python API и Node.js + SQLite. Открыты все десять страниц и все 190 карточек / 22 готовых состава в каждом режиме. Проверены навигация и локальные ссылки, поиск, сортировка, фильтры, пагинация, сравнение, избранное, оба порядка подбора деталей, TXT и общая ссылка, неверный бюджет, повреждённые параметры, ошибка API без сброса состава.

Проверены мобильные страницы и обе темы без горизонтальной прокрутки. В Node-режиме выполнены сохранение, повторное открытие, изменение, копия, удаление, чтение из изолированной сессии без авторских прав, отказ сохранения и успешный повтор. Для аккаунта: регистрация с переносом гостевых сборок, выход, ошибка пароля, повторный вход, вход из изолированного контекста и отдельный аккаунт без доступа к чужим изменениям. Возврат фокуса окна сохраняет введённые поля.

## Облачная и локальная версии

Прежняя облачная версия опубликована успешно как версия 1 на Cloudflare Workers + D1. Применённая тогда схема содержит четыре таблицы; в облачном каталоге подтверждены 220 строк (190 моделей + 22 состава + 8 предложений). Пользователь **подтвердил сохранение сборки и открытие полученной ссылки** на публичном сайте.

Прямое HTTP-обращение к этому домену из исполнителя блокируется прокси CONNECT 403. Подтверждение пользователя и проверка схемы D1 не являются полным независимым тестом всех облачных действий.

По последующему запросу подготовлен **локальный комплект с регистрацией**. Новая схема с семью таблицами и код аккаунтов не публиковались на прежний адрес. Интернет-адрес не переименован: доступный инструмент хостинга меняет название, а не домен. Для защиты используйте **http://localhost:8080/** — в этом адресе нет личного имени/почты. Он работает, пока запущен сервер на этом компьютере.

Локальная база создаётся в `instance/sobrano.sqlite`; облачная D1 — отдельная база. Их пользовательские записи не синхронизируются автоматически. Прежний GitHub Pages остаётся статическим просмотром, не полноценным сервером.

## Исправленные при проверке ошибки

1. Одновременный перенос двух гостевых списков мог превысить квоту 50. Проверка перенесена внутрь атомарной SQL-операции; добавлен тест гонки.
2. Обновление сессии при возвращении из другой вкладки пересоздавало форму и стирало введённые значения. При прежнем пользователе DOM формы сохраняется; добавлена браузерная проверка.
3. Прежняя HTTP-выдача Python допускала ресурсы вне интерфейса. Добавлен белый список и проверка существующей приватной базы во временной папке.
4. Проверки фиксированного количества страниц обновлены для десятой страницы аккаунта. В статическом режиме показывается понятная инструкция запуска, а не имитация входа.

## Ограничения для честной защиты

- Нет восстановления пароля, административной панели магазина, оплаты и реальных заказов. Приложенный файл ПМ 6 этих функций не требует.
- 100000 итераций PBKDF2 выбраны с учётом предела выбранного облачного WebCrypto. Для массового публичного сервиса требуется отдельная оценка защиты паролей и нагрузки; этот комплект проверен как учебный проект.
- Только 8 датированных магазинных предложений для 7 моделей; остальные цены помечены как расчётные. Автоматического обновления цен нет.
- Не все фото точного артикула; примеры линейки подписаны. Внешние источники из данной среды недоступны; текущая загрузка всех внешних изображений не подтверждена. Полного проверенного офлайн-кеша в комплекте нет.
- Недостающие размеры и разъёмы не означают гарантированную совместимость. BIOS, QVL и охлаждение проверяются не полностью.
- Финальная графическая проверка Python-окна и снимки для слайдов нужны на компьютере защиты. Прочитайте [сценарий на 5–6 минут](../DEFENSE.md) и выполните демонстрацию из [README](../README.md).

## Сохранность исходников

До изменений создан ZIP прежнего состояния `sobrano-before-accounts-2026-10-28.zip`. Старые рабочие папки сохранены. Применённая миграция `0000` не редактировалась: добавлена отдельная `0001`. Приватные базы, cookie, токены, зависимости, двоичный Python-кеш и технические скриншоты не включаются в готовый ZIP исходников.
