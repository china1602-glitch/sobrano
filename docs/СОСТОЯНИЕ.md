# Состояние проекта · версия 1.1

## Завершено

- [x] Отдельный проект, не изменяющий СОБРАНО.
- [x] Настройки практики, редактируемые сроки, план и длительность часа: 60 или 45 минут.
- [x] Задачи: создание, изменение, удаление, статусы, поиск, приоритет и сортировка на Python.
- [x] Дневник: одна запись на день, время и перерывы, связь с задачей и направлением.
- [x] Календарь по месяцам с реальными записями и переходом к добавлению или редактированию дня.
- [x] Открытие существующей записи сегодняшнего дня вместо создания дубликата.
- [x] Python-проверки и расчёт фактических минут.
- [x] Пересчёт минут в часы по 60 или 45 минут, план в выбранной единице и совместимость старых профилей и резервных копий.
- [x] Постоянное хранение в SQLite, транзакции, внешние ключи.
- [x] Статистика, недельная диаграмма, часы по направлениям.
- [x] Печатный отчёт за период и CSV.
- [x] JSON-копии, проверяемое восстановление и сохранение предыдущего состояния.
- [x] Защита от перезаписи устаревшей вкладкой.
- [x] Предупреждение об уходе с изменённой формы и локальные черновики новой задачи или записи.
- [x] Явная ошибка фильтрации вместо показа старых результатов как новых.
- [x] Отдельная база учебного примера, личная база изначально пустая.
- [x] Светлая и тёмная темы, адаптация к телефону, локальный шрифт.
- [x] Шесть разных локальных иллюстраций и полезных памяток.
- [x] Запуск из VS Code, F5, инструкция и карта исходников.
- [x] Автоматические проверки Python и проверка действий в Chromium.

## Перед использованием на своём компьютере

- [ ] Открыть папку в VS Code и запустить установленным Python.
- [ ] Заполнить настоящие данные практики, согласованный план и длительность часа.
- [ ] При обновлении сохранить прежнюю `storage/` и сделать резервную копию до замены кода.
- [ ] Сверить отчёт с формой, требуемой колледжем.
- [ ] Самостоятельно пройти основной сценарий и разобрать соответствующие функции.
- [ ] Сделать резервную копию перед переносом записей.

## Возможное развитие, не входящее в версию 1.1

- Разные пользователи, авторизация и разграничение доступа к дневникам.
- Проверка записей руководителем с историей согласования.
- Шаблоны официальных документов конкретного колледжа.
- Сетевая публикация Python backend с авторизацией, HTTPS и резервным копированием.

Эти возможности нельзя считать уже реализованными. Версия 1.1 — локальный личный органайзер, а не многопользовательская информационная система колледжа.
