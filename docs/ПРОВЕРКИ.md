# Проверки версии 1.0

Дата: 21.10.2026. Среда проверки: Linux, Python 3.12.14, SQLite 3.53.1, Chromium 151.0.7922.173. Это проверка в среде разработки, а не утверждение о запуске на компьютере студента.

## Автоматические проверки Python

25 тестов пройдены. Команда из папки проекта:

```powershell
py -B -m unittest discover -s tests -v
```

Проверены расчёт минут и границы времени; создание, изменение и удаление задач и дневника; постоянство SQLite между объектами подключения; запрет второй записи на одну дату и будущей даты; период практики; сохранение дневника при удалении связанной задачи; конфликт версий; отдельные базы режимов; поиск и сортировка; отчёт, CSV и экранирование; проверка и откат некорректного импорта; восстановление связей и сохранение предыдущей копии; маршруты HTTP, ошибки запросов и недоступность приватных файлов через сервер.

Тесты создают временные базы. Личные данные не используются и не удаляются.

## Действия в браузере

В Chromium через настоящий Python-сервер проверены:

- Сохранение настроек, создание задачи, смена статуса, поиск и редактирование.
- Ошибка при неверном времени с сохранением текста формы; правильный расчёт 09:00–17:30 минус 60 минут = 450 минут.
- Запрет повторного дня, сохранение после обновления страницы.
- Печатный HTML и сохранение PDF средствами браузера; загрузка CSV.
- Загрузка JSON-копии, удаление дня и восстановление из копии с возвратом часов.
- Переключение учебного примера и личных записей без смешивания баз.
- Памятка, создание связанной по направлению задачи, сохранение темы после обновления.
- Отказ API без стирания формы и конфликт записи из двух вкладок.
- Мобильное меню и загрузка всех локальных изображений.

Проверены 48 сочетаний: шесть страниц, ширины 360 / 390 / 768 / 1440 px, светлая и тёмная темы. Горизонтального переполнения и отсутствующих локальных ресурсов не обнаружено. Ошибок JavaScript в итоговом прогоне не было.

Автоматическая проверка axe-core по WCAG 2 A/AA и 2.1 AA выполнена для шести страниц в обеих темах на ширинах 390 и 1440 px, а также для формы дневника. Нарушений в итоговом прогоне не обнаружено. Автоматический инструмент не заменяет полноценную ручную проверку доступности.

Технические снимки и временные тестовые базы в выдаваемый проект не включены.

## Что проверить на своём устройстве

Запуск F5 в установленном VS Code и печать на конкретном принтере зависят от локального окружения; их следует проверить самостоятельно. Все шаги запуска приведены в README. Для работы проекта не нужны Playwright, axe-core или Node.js — это инструменты проверки в среде разработки.

Сетевое размещение, несколько пользователей и официальное согласование дневника не входят в эту версию. Приложение слушает только локальный адрес; рабочая база не предназначена для открытого размещения в Интернете.
