## Что исправлено

1. **Проверка диапазона цены.** Перепутанные границы теперь дают понятное сообщение рядом с полями. Некорректная форма не отправляется в API. При прямой ссылке с таким диапазоном показано объяснение исправления.
2. **Устаревшие параметры ссылок.** Интерфейс очищает неизвестные категорию, сортировку и режим совместимости, а также некорректные числовые ограничения. Ранее Python отвергал такие параметры, хотя статическая версия пыталась их игнорировать.
3. **Синхронизация вкладок.** Событие очистки всего localStorage обновляет открытый конфигуратор и списки, как изменение основного ключа состояния.
4. **Адрес API.** API-клиент нормализует завершающий слеш, чтобы относительный адрес `api` сохранял подпапку проекта.
5. **Локальный сервер.** Закрыта HTTP-выдача скрытых служебных путей (.git, .vscode, .env), включая URL-кодирование. Добавлена проверка GET/HEAD.
6. **Windows и VS Code.** Перенесено отключение Python-кэша, добавлено скрытие кэша в редакторе и задачи запуска API, статического сайта и тестов.
7. **Внешний вид.** Сохранены адаптивная минималистичная вёрстка и обе темы. Светлая тема стала начальной; явный выбор пользователя сохраняется.
8. **Документация.** Созданы корневые DEFENSE.md и FRONTEND_BACKEND_GUIDE.md, обновлён README с текущими путями, запуском, тестами и инструкцией отправки ветки.

## Реальный Python-бэкенд

Бэкенд существовал как законченная серверная логика, а не как заглушки. Он использует стандартную библиотеку Python. Данные поступают из JSON проекта.

Проверены маршруты:
- GET /runtime.json — режим python при запуске server.py;
- GET /api/health — диагностика процесса;
- GET /api/catalog — модели, сборки, предложения, цены, результаты сборок;
- GET /api/products — поиск, фильтры, сортировка, совместимость и поднабор избранного;
- GET /api/builds — назначение и бюджет;
- POST /api/configuration — проверка состава, бюджет и оценка кандидатов.

Проверка выполнена на Windows, Python **3.13.14**, Node.js **24.14.0**, установленный Google Chrome без окна.

Кроме интеграционных тестов выполнен обычный запуск:

```powershell
python server.py --port 18082
```

Из PowerShell выполнены Invoke-RestMethod к health, runtime, products и configuration. Фактический результат:

```json
{
  "Backend": "Python",
  "Python": "3.13.14",
  "Products": 190,
  "Builds": 22,
  "Offers": 8,
  "Runtime": "python",
  "RyzenResults": 25,
  "RTX4090Selected": 85,
  "PK550DAllowed": false,
  "CheckStatus": "incomplete"
}
```

`incomplete` корректен: выбран только GPU, остальные обязательные компоненты отсутствуют. Запрос с составом `{"parts":{"gpu":85}}` запрещает кандидата p40 с недостаточной мощностью.

В браузерной проверке Python-режима клиентские функции проверки совместимости и цен специально заменены функциями, выбрасывающими ошибку. Выбор GPU и отбор БП продолжили работать через сервер. Network содержит запросы catalog/products/builds/configuration. В статическом режиме запросов /api/ нет.

При тестовом HTTP 503 от configuration интерфейс показывает ошибку, сохраняет предыдущие select и localStorage. Подмена ответа выполняется только в тестовом Chrome; данные и сервер проекта не подменяются.

## Ограничения и непроверенные вручную действия

Критических нерешённых сбоев в проверенных сценариях не выявлено. Сохраняются ограничения исходного набора данных:

- У Ryzen 7 5700X3D OEM нет подтверждённого фото; используется подписанная заглушка. Для части других моделей показан подписанный пример линейки/исполнения.
- Часть физических размеров и параметров питания отсутствует; неизвестные данные дают предупреждения. Физическая совместимость BIOS/QVL/разъёмов не гарантируется.
- Сохранённые предложения не являются онлайн-прайсом. Большинство цен — явно подписанные учебные оценки. Автоматического обновления и подтверждения наличия нет.
- Внешним фото нужен Интернет. Полная загрузка всех фото у всех поставщиков не подтверждена.
- Аккаунтов, платежей и серверного хранения пользовательских сборок нет; они не имитируются.
- Ручной GUI-сеанс отладки F5 в VS Code и реальная публикация Pages не выполнялись. Настройки и инструкция подготовлены; обычный запуск и API проверены фактически.
- Автоматическая проверка скачивания TXT не подтверждает доступность системного буфера обмена: при запрете clipboard интерфейс предлагает скопировать выделенную ссылку вручную.

Каталог и предложения не изменены. Разница байтов между local и GitHub-копией связана с LF/CRLF; данные совпадают после нормализации переводов строк. В Git оба JSON остаются без изменений.
