# Изображения, шрифт и материалы

- `hero.svg`, `favicon.svg`, `web.svg`, `data.svg`, `testing.svg`, `git.svg`, `docs.svg`, `team.svg` — векторные иллюстрации, созданные для этого проекта. У каждой памятки свой рисунок; это схемы, а не фотографии реальных организаций или студентов. Никаких внешних запросов за картинками приложение не выполняет.
- Manrope хранится локально в `web/assets/fonts/`. Лицензия SIL Open Font License 1.1 включена в `OFL.txt`; шрифт разрешено распространять с соблюдением этой лицензии.
- Памятки — краткие учебные тексты проекта с практическими заданиями, не документы колледжа и не сертификационные материалы. Приблизительное время выполнения — ориентир, не измеренная длительность.
- В `data/guides.json` указаны официальные справочные ресурсы: MDN Web Docs, Python Documentation, SQLite, Git Book, GitHub Docs. Ссылки служат для дальнейшего изучения; тексты страниц не скопированы в проект. Их доступность зависит от Интернета и возможных изменений адресов.
- Учебный пример содержит явно обозначенные вымышленные задачи и записи. Он не является подтверждением прохождения практики. Личная база изначально пустая.
