# Источники фотографий

Набор проверен 20.10.2026. В действующем каталоге 190 товаров: у 189 есть изображение, у одной модели пока показан нейтральный значок «Фото не добавлено». Из доступных изображений 93 относятся к указанной модели (`exact`), 96 показывают соответствующую линейку или одно из исполнений графического процессора (`family`). Это число карточек товаров, а не уникальных файлов. Реальные счётчики можно получить через `SobranoMedia.coverage()`.

`js/product-images.js` содержит дополнительные проверенные ссылки и метаданные. `js/media.js` сопоставляет их с названиями товаров, сохраняет приоритет 13 ранее добавленных свободных фотографий и формирует подписи. Изображение одной категории не подставляется всем товарам. Например, фото NV2 не используется для NV3, а MSI VENTUS не заменяется на Founders Edition.

Для линейки видна подпись «Изображение линейки». Подробное пояснение показывается на странице товара. У фотографий BOX для позиции OEM видна отдельная подпись о коробке и кулере; сама модель CPU совпадает. Суффиксы OEM/BOX нормализуются только у AMD Ryzen и Intel Core. Изображение AMD Ryzen 7 5700X3D пока исключено: найденный файл нельзя уверенно отнести к этой модели.

Фотографии загружаются с внешних HTTPS-серверов. Доступность может зависеть от сети и политики сервера источника. При ошибке используется не более одной запасной ссылки, затем появляется нейтральный значок. Для Corsair 4000D AIRFLOW обе ссылки ведут на JPEG-превью: оригинальный TIFF 40 МБ браузер не загружает.

У свободных фотографий ниже сохранены автор и лицензия. Для материалов производителей и Newegg показана ссылка «Источник»; эти названия обозначают источник, а не установленного фотографа. Их изображениям не приписывается Creative Commons. Ссылка на источник сама по себе не означает свободную лицензию.
