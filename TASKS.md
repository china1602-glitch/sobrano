# Выполнено и оставшиеся задачи

## Выполнено

- Сохранены существующие 190 моделей, 22 сборки, старые сохранения и относительные пути GitHub Pages.
- Упрощены главная, оформление и навигация; сохранены светлая и тёмная темы.
- Мобильные фильтры свёрнуты, меню раскрывается по кнопке.
- Добавлены фильтры по характеристикам всех восьми категорий, вид списком и плиткой.
- Характеристики получили названия и единицы измерения.
- Добавлены постоянные ссылки моделей и составов сборок.
- В сборках сразу видны CPU, GPU, память и накопитель.
- Исправлены сохранение переданной сборки, повреждённые ссылки, фокус полей и синхронизация между вкладками.
- Неизвестные параметры совместимости дают отдельное предупреждение, неизвестная мощность не превращается в расчёт БП на 250 Вт.
- Снимки фотографий привязаны к моделям, а не к категориям; сохранены источники и лицензии.
- Добавлены 8 ценовых снимков из 3 магазинов для 7 моделей; тип и дата цены видны пользователю.
- Добавлены локальные файлы шрифта, документация архитектуры и проверки расчётов.

## Осталось по содержанию

- Подобрать и проверить фотографии для 177 моделей. Чужие изображения не подставляются.
- Заполнить недостающие размеры и параметры питания: в исходном наборе у 42 из 47 GPU не указана длина конкретной платы.
- Расширять подтверждённые предложения магазинов и регулярно проверять даты, города и комплектации. Для 183 моделей пока используются учебные оценки.
- Проверять характеристики по конкретным артикулам и первичным страницам производителей; все 190 наборов параметров не прошли новую индивидуальную сверку.
- Автоматическое обновление цен потребует отдельного разрешённого источника данных и серверной части; в текущей версии его нет.

## Публикация

Изменения подготовлены в отдельной ветке для проверки. Публикация на действующем сайте выполняется только после согласования: слияние ветки в `main` запускает GitHub Pages. При необходимости предыдущая версия доступна в истории Git.
